# Phase 1 成果物: ポリシー草案アウトライン（12-policy-drafts-outline）

## Goal
本番公開前に必要な文書群（利用規約、プライバシーポリシー、返金ポリシー、店舗掲示）の骨子を作る。

## Context
本端末は決済情報、ウォレットアドレス、取引履歴、問い合わせ情報を扱う可能性がある。

## Constraints
- ここではアウトラインのみ作成し、法的確定文言は専門家レビュー後に確定する。

## 1. 利用規約アウトライン
- 提供主体、適用範囲。
- 取り扱う決済方式・対応チェーン。
- 期限切れ、重複送金、誤送金の扱い。
- 返金条件、手数料、所要日数。
- 免責事項（ネットワーク混雑、外部ウォレット障害）。
- 禁止事項（不正利用、なりすまし）。
- サービス停止条件（障害、法令対応、緊急停止）。

## 2. プライバシーポリシーアウトライン
- 取得データ（取引情報、端末識別子、問い合わせ情報）。
- 利用目的（決済処理、不正検知、監査、サポート）。
- 第三者提供の有無（監査法人、クラウド、分析ツール）。
- 保存期間、削除方針。
- 開示請求窓口。

## 3. 返金ポリシーアウトライン
- 返金対象ケース（過入金、重複、期限後着金など）。
- 返金不可ケース（誤チェーン・誤トークン等の扱い）。
- 返金手順（申請、審査、承認、実行）。
- 返金時の必要情報（請求ID、tx hash、連絡先）。
- 手数料・ガス代負担者。

## 4. 店舗掲示アウトライン
- 対応ウォレット・対応チェーン。
- 期限・再発行ルール。
- トラブル時の問い合わせ先。
- 返金方針の要点。
- スタッフがシードフレーズを尋ねない旨。
