# 店頭掲示証跡テンプレート（posting-evidence-template）

## Goal

店頭掲示物の設置・確認・更新の証跡を標準化し、商用Go審査・監査の証拠として残す。

## Context

- 商用Goの条件として、店頭掲示物の設置証跡が必要。
- 証跡は `docs/production/evidence/<timestamp>/` に保存する。
- 証跡ファイル名: `posting-evidence-<STORE_ID>-<YYYYMMDD>.md`

---

## 保管ルール

- 証跡ファイルは `docs/production/evidence/<timestamp>/posting-evidence-<STORE_ID>-<YYYYMMDD>.md` に保存する。
- 写真ファイルは同ディレクトリに保存する（または参照リンクを記録する）。
- 証跡は監査目的で保持期間中は削除しない。

## Failure-handling

- 掲示証跡がない店舗での商用展開は禁止。
- 掲示内容がポリシーと乖離した場合は即時更新・再証跡を取得する。
- 写真が撮影できない場合は代替確認方法を記録し、承認者の署名を得る。
