## Pre-release checks
- 端末でログインできる
- 請求作成できる
- `/pay?ref=` から顧客ページが開く
- ネットワーク `Polygon` / トークン `JPYC` / 送金先 / 金額が表示される
- manual review の連絡導線がある
- 返金記録と返金検証の担当者が決まっている
- 日次締めの担当者が決まっている
- backup 実行担当と保存先が決まっている
- 障害連絡先が共有済み
