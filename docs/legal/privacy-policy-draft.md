## 2. 取得する情報

本サービスでは、以下の情報を取得・処理します。

### 2-1. お客様が直接入力する情報

本サービスはお客様が直接入力するフォームを提供しません。秘密鍵・シードフレーズの入力欄もありません。

### 2-2. 取引・支払いに伴い自動的に取得される情報

| 情報 | 取得タイミング | 個人情報・個人関連情報の該当性 |
|---|---|---|
| 請求ID（invoice_id） | 請求生成時 | 識別子（単体では個人特定不可だが、他情報と組み合わせて個人関連情報になり得る） |
| 送金元ウォレットアドレス | 送金検知時 | 個人関連情報（他の情報と組み合わせで特定可能になる場合あり） |
| 取引ハッシュ（tx hash） | 送金検知時 | 個人関連情報（ブロックチェーン上で公開） |
| 送金金額・送金タイムスタンプ | 送金検知時 | 個人関連情報 |
| IPアドレス | アクセス時 | 個人関連情報（特定可能になる場合あり） |
| ユーザーエージェント | アクセス時 | 個人関連情報 |
| 店舗ID・端末ID | 請求生成時 | 事業者識別情報 |
| 審査・返金申請時の記録 | 申請時 | 問い合わせ内容により個人情報を含む場合あり |

> **注**: 本サービスで取り扱うウォレットアドレスが「個人情報」（個人を直接特定するもの）または「個人関連情報」（容易に照合できるもの）のいずれに該当するかは運用実態・照合可能性によります。法務責任者が確認してください。（外部承認が必要）

## 3. 利用目的

取得した情報は以下の目的のみに利用します。

| 利用目的 | 対象情報 |
|---|---|
| JPYC決済の処理・確認 | 請求ID、ウォレットアドレス、tx hash、金額、タイムスタンプ |
| 異常取引・不正利用の検知 | IPアドレス、ウォレットアドレス、金額、取引パターン |
| 審査・確認（review_required 対応） | 請求ID、tx hash、ウォレットアドレス、金額 |
| 監査・証跡管理 | 全操作ログ（audit_logs） |
| お客様サポート・問い合わせ対応 | 申請時に提供された情報 |
| 法令上の記録・保存義務への対応 | 取引記録全般 |

利用目的外での利用は行いません。目的外利用が必要な場合は、法令の認める範囲でのみ行います。

## 6. 安全管理措置

- ハッシュチェーン付き監査ログによる改ざん検知
- アクセス制御（スタッフPIN・セッション管理）
- 本番DBの暗号化ストレージ保管（FileVault / LUKS）
- バックアップの暗号化保管（アクセス制御された保管先）
- HTTPSによる通信暗号化
- SERVICE_INGEST_SECRET等の機密情報はSecret Manager管理（本番）
