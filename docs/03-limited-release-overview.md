# 限定店舗実証リリース概要（03-limited-release-overview）

## Goal
実証協力先に、今回のリリース範囲、非対応範囲、運用前提を簡潔に伝える。

## 対象範囲
- Polygon 上の JPYC
- 限定店舗 / 限定端末
- 顧客ウォレット起点の送金
- 着金確認、manual review、返金記録、日次締め、監査ログ

## 対象外
- カストディ
- 自前オンランプ
- 多チェーン展開
- 広域営業展開向けのスケール構成

## 重要前提
- 顧客の秘密鍵は保持しない
- 実送金は顧客ウォレット側で実行する
- review が発生した場合は店舗スタッフが runbook に従って対応する
- 実証リリースの Go は証跡ベースで判断する
