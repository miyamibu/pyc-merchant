# 外部承認項目一覧（open-questions）

## Goal
推測で埋めると危険な項目を先に列挙し、人間承認が必要な論点を明示する。

## Context
この文書は Phase 0〜2 のゲート管理台帳として使う。

## 外部承認項目（外部承認が必要）
| ID | 論点 | 影響 | 必要な判断者 |
|---|---|---|---|
| Q-001 | 運用形態（自社店舗のみ/他社提供） | 法規制、契約、責任範囲 | 法務責任者 |
| Q-002 | 登録・届出の要否 | 事業継続可否 | 法務責任者 |
| Q-003 | 対応チェーンの確定 | UX、手数料、監視難易度 | 技術責任者 + 運用責任者 |
| Q-004 | JPYCコントラクトの確定値 | 誤送金/検知不全リスク | 技術責任者 |
| Q-005 | 期限300秒と完了判定ポリシー | 期限後着金・顧客体験 | 技術責任者 + CS責任者 |
| Q-006 | 返金ポリシー（責任・期限・手数料） | 顧客トラブル、会計 | 運用責任者 + 会計責任者 |
| Q-007 | 返金ウォレット保管方式 | セキュリティ・監査 | セキュリティ責任者 |
| Q-008 | ウォレット対応範囲 | サポート負荷、テスト範囲 | プロダクト責任者 |
| Q-009 | 会計処理（税・評価・仕訳） | 締め処理、監査 | 会計責任者 |
| Q-010 | 本番Go判定条件 | リリース可否 | 四責任者（法務/会計/運用/技術） |

## 外部仕様の再確認が必要な項目
- 金融庁制度更新差分（電子決済手段等取引業周辺）。
- JPYC公式が提示する最新の発行/償還/対応チェーン仕様。
- Reown AppKit/WalletConnectの現行サポート範囲。

## Done when
- すべての `外部承認が必要` 項目に責任者と期限が入る。

## Validation
- 各Phase成果物で本ファイルのIDを参照する。

## Failure handling
- 判断待ち項目が残る場合、該当機能の実装を開始しない。
